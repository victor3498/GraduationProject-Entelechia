## pc端(先实现)
  #登录界面：左侧装饰图，点击‘登陆账号’后右侧界面切换：输入用户名，密码，(图片验证码？后继可考虑补充)，登陆按钮。登录按钮右下角蓝字“没有账号？现在注册”

  #注册界面：登录初始界面点击‘注册’或者蓝字后右侧切换：输入用户名、(邮箱？后继考虑补充)、密码、再次确认密码。注册按钮

  #主页：左边侧边栏垂直显示：（用户头像？后继补充）、登出按钮、所有文档、星标文档、用户界面。
        侧边栏右边：文档列表显示栏，上部分搜素框，小图标上下箭头按钮--改变排列顺序：创建时间前后，上次打开前后时间。小图标按钮创建文档
       
       下部分展示列表，单个文档展示块左端星标按钮--按动可以修改星标与否，中间部分文档名，右边两个小图标按钮--删除和重命名，展示内容随侧边栏按钮‘所有文档’‘星标文档’切换。鼠标在对应展示块上停留几秒后浮窗显示文档详情，点击后再右侧编辑区显示内容进入编辑。

       最右侧为编辑区，使用tiptap示例编辑器(后继需要修改样式)


   #创建文档界面：小弹窗，输入文档名

   #用户界面：切换主页侧边栏内容显示，显示用户名，(邮箱？头像？)，左上角按钮‘返回’

   #重命名界面：小弹窗，输入新文档名

## 界面安排
  一、PC端界面设计（优化后的专业描述）
1 登录页面（Login Page）
布局结构

整体采用 左右分栏布局（Split Layout）：

区域	内容
左侧	装饰图 / 品牌插画 / 项目Logo
右侧	登录 / 注册表单区域
登录表单

组件结构：

标题：账号登录

输入框

用户名

密码

（可选）图片验证码

登录按钮

辅助操作

蓝色文字链接：没有账号？立即注册

交互逻辑

点击 立即注册 → 右侧表单切换为 注册表单

登录成功 → 跳转到 主页（Dashboard）

2 注册页面（Register Form）

注册页面 不单独新页面，而是在 登录页右侧区域切换表单。

表单字段

用户名

邮箱（可选）

密码

确认密码

操作按钮

注册按钮

交互逻辑

注册成功 → 自动跳转登录

或自动登录进入主页

3 主页面（Dashboard）

主页面采用 三栏布局：

┌───────────────┬─────────────────────┬────────────────────┐
│ Sidebar       │ Document List       │ Editor             │
│ (侧边栏)      │ 文档列表             │ 编辑区             │
└───────────────┴─────────────────────┴────────────────────┘
4 左侧边栏（Sidebar）

垂直导航结构：

内容

用户头像（可选）

导航按钮

所有文档

星标文档

用户中心

登出按钮

交互逻辑
操作	结果
点击所有文档	列表显示全部文档
点击星标文档	只显示星标文档
点击用户中心	切换为用户信息界面
点击登出	返回登录页
5 文档列表区域（Document List Panel）

该区域分为 两个部分：

上方工具栏（Toolbar）

包含：

元素	作用
搜索框	按文档名称搜索
排序按钮	创建时间 / 最近打开
排序方向按钮	升序 / 降序
新建文档按钮	打开创建文档弹窗
下方文档列表（Document List）

列表中的 单个文档卡片（Document Item）：

⭐ 文档名                  🗑 ✏

结构：

位置	元素
左侧	星标按钮
中间	文档名称
右侧	删除按钮 / 重命名按钮
交互
操作	结果
点击文档	在右侧编辑区打开
点击星标	切换星标状态
点击删除	删除文档
点击重命名	打开重命名弹窗
鼠标悬停	显示文档详情 Tooltip

Tooltip内容：

创建时间

上次编辑时间

文档字数

6 编辑区（Editor Area）

右侧为 富文本编辑区域。

使用：

Tiptap Editor

包含：

工具栏

编辑区

自动保存提示

后期可增加：

Markdown 支持

文档历史

协作编辑

7 创建文档弹窗（Create Document Modal）

点击 新建文档按钮 触发。

内容

输入框：文档名称

创建按钮

取消按钮

创建成功：

新文档加入列表

自动进入编辑状态

8 重命名弹窗（Rename Modal）

结构：

输入框（新文档名）

确认按钮

取消按钮

9 用户中心（User Profile Page）

点击 侧边栏用户中心 切换。

内容

用户名

邮箱

头像

操作

左上角按钮：

返回主页

用例ID	UC01
角色	用户
用例说明	用户注册新账户，用户名不重名，密码符合格式要求
前置条件	进入注册界面
基本事件流	                                               参与者动作：
1.1 点击注册或“立即注册”                                    1.2 进入注册标签页
2.1 填写用户名、密码以及确认密码                             2.2 验证输入
3.1 点击“注册”	系统响应：                                  3.2 提示注册成功，若用户名已存在则进入3.2.1，若两次密码不一致则进入3.2.2，若密码不合规范则进入3.2.3


其他事件流	无
异常事件流	3.2.1 系统提示“用户名已存在”
3.2.2 系统提示“两次密码不一致”
3.2.3 系统提示“密码至少8位，最多13位，需要包含数字与字母”
后置条件	成功注册，可以进行登录
备注	无

## 非功能性需求分析

### 3.3.1 性能需求
（1）文档加载：文档内容加载时间不超过1秒，大型文档（10000字以上）加载时间不超过3秒。
（2）编辑器响应：用户输入时编辑器响应延迟不超过100ms，确保流畅的编辑体验。
（3）保存响应：文档保存操作完成时间不超过500ms。
（4）列表渲染：文档列表页面加载时间不超过800ms，支持1000条以上文档的快速滚动。
（5）图片处理：图片上传与渲染时间不超过2秒，支持2MB以内图片的即时预览。
（6）CPU使用率：正常编辑时CPU使用率不超过40%，图片处理时瞬时峰值不超过75%。
（7）内存占用：编辑器运行时内存占用不超过500MB，长时间使用无明显内存泄漏。

### 3.3.2 安全性需求
（1）用户认证：采用JWT令牌认证机制，令牌有效期设置为2小时，支持自动刷新。
（2）密码安全：用户密码采用BCrypt算法加密存储，密码强度要求至少8位，包含数字和字母。
（3）数据传输：所有API请求采用HTTPS协议，防止数据传输过程中的窃取和篡改。
（4）文件存储：用户上传的图片存储在应用私有目录，文件名采用UUID加密，防止路径遍历攻击。
（5）权限控制：实现基于角色的访问控制，普通用户仅能访问和修改自己的文档。
（6）会话管理：用户退出登录时立即清除本地存储的令牌信息，防止会话劫持。
（7）输入验证：对所有用户输入进行严格的参数校验，防止SQL注入和XSS攻击。
（8）权限最小化：仅在必要时申请设备权限（如相机、存储），并提供权限使用说明。
